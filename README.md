# POWER-BI-SALES-DASHBOARD
Interactive Sales Performance Dashboard built in Power BI to analyze sales, profit, quantity, regional performance, and category insights. Features dynamic slicers, KPI cards, trend analysis, profit distribution, and key influencer visuals for data-driven business decision-making and performance tracking.


The dashboard enables users to monitor business performance efficiently by transforming raw sales data into meaningful insights using advanced data visualization techniques and KPI analysis. It provides a centralized platform for tracking sales growth, identifying profitable product categories, analyzing regional contributions, and supporting strategic business decision-making.

## Features

- Interactive KPI Cards displaying:
  - Total Orders
  - Total Sales
  - Total Profit
  - Total Quantity
  - Profit Margin Percentage

- Sales Analysis by Category
- Profit Distribution Visualization
- Regional Sales Performance Analysis
- Sales Trend Analysis using Order Date
- Key Influencer Analysis for business insights
- Dynamic Filters and Slicers for interactive exploration
- User-friendly and visually optimized dashboard design

## Technologies Used

- Power BI
- DAX (Data Analysis Expressions)
- Data Visualization
- Business Intelligence
- Data Analytics

## Objective

The main objective of this project is to build a data-driven business dashboard capable of analyzing and visualizing sales performance effectively. The dashboard helps organizations identify business trends, improve decision-making, and gain actionable insights from sales data.

## Business Insights Generated

- Identification of top-performing categories
- Analysis of profit contribution by products
- Regional sales comparison and trend analysis
- Performance monitoring through KPI metrics
- Interactive exploration of sales data using filters
